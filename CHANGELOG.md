# Changelog

All notable changes to **Instagram Follow Checker Pro** will be documented in this file.

The format is based on **Keep a Changelog**, and this project adheres to **Semantic Versioning**.

## [30.8.0] - 2026-11-21

### Added
- **CIT v10 Integrity Engine:** Multi-layer reconciliation across REST API, GraphQL, Trie prefix sweep, Live Modal DOM capture, and `show_many` batch verification.
- **Suspicious & Bot Account Detection:** Heuristic flagging for inactive, ghost, and suspected automated accounts.
- **Account Management Tools:** Protection whitelist, favorites, custom user notes, and tagging support.
- **Official Instagram JSON Import:** Import official Instagram data export archives for offline cross-checking.
- **Keyboard Shortcuts:** Added `Enter`, `/`, `1-9`, `Shift+Click`, and `Esc` navigation shortcuts.

### Changed
- Improved anti-ban quota pacing and automatic cooldown break intervals.
- Refined TR/EN localization strings across all 6 UI themes.

## [30.4.0]

### Added
- Initial multi-layer REST and GraphQL follower/following sweep engine.
- Anti-ban request rate limiter and session quota tracking.
- Export support for CSV, JSON, and TXT formats.
- 6 customizable UI themes with Turkish (TR) and English (EN) language support.
